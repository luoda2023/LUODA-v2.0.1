## 二、被控端必须满足的两个授权

这是本次问题的核心。**两个授权互相独立，缺一不可**：

| 授权 | 位置 | 何时失效 | 缺失时的现象 |
|---|---|---|---|
| **无障碍服务**「LDesk Input」 | 设置 → 无障碍 → 已安装的服务 → LDesk Input | 系统更新 App、被「强行停止」后掉；卸载必掉。重启手机**不**掉 | **能看不能操作** |
| **录屏/投屏**（MediaProjection） | 会话建立时弹出的系统对话框 | **每次 App 重启后都要重新允许** | 黑屏 / 一直「等待画面传输」 |

> 华为开启无障碍时会先弹「安全提醒」风险页：必须先勾选「我已知晓如上风险」，底部的「开启」按钮才会从灰色变为可点。

### 系统层判据

```bash
ADB="G:/Android/sdk/platform-tools/adb.exe"

# 无障碍是否开启
"$ADB" -s <serial> shell settings get secure enabled_accessibility_services
# 期望包含：com.luoda.remote/com.luoda.remote.InputService

# 是否已被系统绑定（= App 侧 InputService.ctx 已就绪）
"$ADB" -s <serial> shell dumpsys accessibility | grep -m1 -A2 "Bound services"
# 期望看到：Service[label=LDesk Input, ..., capabilities=33]
#   33 = CAN_RETRIEVE_WINDOW_CONTENT(1) | CAN_PERFORM_GESTURES(32)

# App 侧是否真的连上（ctx 在 onServiceConnected 置位）
"$ADB" -s <serial> logcat -d | grep "input service"
# 期望：D input service: onServiceConnected!
```

> Android 硬限制：第三方 App **无法**自己开启无障碍服务，`adb shell settings put secure` 也会被拒（缺 `WRITE_SECURE_SETTINGS`）。所以「自动默认开通」只能落地为「首次安装引导一次 + 丢失后立刻发现 + 一键恢复」。

## 五、修复：「全屏后没有返回/主页按键」

### 它不是固定按钮，是一条悬浮条

```
DraggableMobileActions  (common/widgets/overlay.dart:173)
  ├─ 尺寸 200 × 45（随画面缩放）
  ├─ 外观：半透明蓝色圆角卡片，可拖动
  └─ 按钮：← 返回   🏠 主页   ⋯ 最近任务   ▏ 隐藏
```

调用链：

```
desktop/pages/remote_page.dart:402-423
  └─ if (!ffiModel.isPeerAndroid) → Offstage()          // 仅 Android 被控端才有
     else Obx(() => Offstage(
            offstage: dialogManager.mobileActionsOverlayVisible.isFalse,   // ← 这里被关掉了
            child: Overlay(initialEntries: [ makeMobileActionsOverlayEntry(...) ])))

common.dart:965  makeMobileActionsOverlayEntry
  └─ onBackPressed   → inputModel.onMobileBack()    // 发 VK_LDESK_BACK
     onHomePressed   → inputModel.onMobileHome()
     onRecentPressed → inputModel.onMobileApps()

common.dart:786  loadMobileActionsOverlayVisible
  └─ visible = bind.getLocalFlutterOption('showMobileActions') != 'N'
```

### 根因

配置文件 `%APPDATA%/LDesk/config/LDesk_local.toml` 中：

```toml
[ui_flutter]
showMobileActions = 'N'          # ← 悬浮操作条被关闭
draggablePositionMobile = '667.2,444.0'
```

### 处理

已把 `showMobileActions` 改回 `'Y'` 并重启 App 生效。

### 如何自己开关

远端窗口把鼠标移到**顶部**唤出工具栏 → 点那个**手机形状的图标**（`assets/actions_mobile.svg`，提示文字 `Mobile Actions`，见 `remote_toolbar.dart:376`）。它是个开关：再点一次就隐藏。

> 另一条路：工具栏的**键盘图标**菜单最底部也有一组 `Back / Home / Apps / Volume up / Volume down / Power`（`remote_toolbar.dart:1916` 的 `...mobileActions()`），同样是 Android 被控端专属。

## 六、调试坑（下次省时间）

1. 手机端「连接」按钮是 ID 输入框右侧的**蓝色箭头**；它左边那个按钮是**清空**，点错会把已输入的 ID 清掉。
2. 输入 ID 后要先按 `KEYCODE_BACK` 收起软键盘再点连接，否则键盘顶起导致按钮位移。
3. 被控端镜像画面是**可缩放可平移**的画布：竖滑会被本地视图消费（日志 `start oneFingerPan`），坐标映射会漂移，每次点击前需重新两点标定。
4. 移动端工具栏的键盘面板里有 `主页 / Esc / Tab / End / Ins / Del / PgUp / PgDn / Ctrl+C / Ctrl+V / Ctrl+S` 等特殊键。
5. 华为打开无障碍设置的显式组件需转义 `$`：
   ```bash
   adb shell 'am start -n "com.android.settings/.Settings\$AccessibilitySettingsActivity"'
   ```
   （不转义会退化成 `com.android.settings/.Settings`，跳到「关于手机」）
